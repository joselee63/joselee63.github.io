섹터 강도

제목 클릭 = 정렬(다시 클릭하면 반대로) · 섹션 이름 클릭 = 결과표에서 그 섹션만 보기 · 거래대금 = KRX 집계(목록이 없는 날은 종가×거래량 근사) · 저항 돌파/지지 이탈 = 돌파·이탈 후 유지 중인 종목 수 · 지수·ETF 섹션 제외

종목별 결과표

숫자 칸 아래 입력창: 위 = 최소, 아래 = 최대 (예: 5일% 최소 5, 거래량배수 최소 2) · 제목 클릭 = 정렬 · 종목명 클릭 = 바로 아래에 차트 펼치기 (다시 클릭하면 접기)
경과일 = 추세선 돌파·이탈 후 지난 거래일 (D+0 = 오늘 돌파, 돌파한 선 아래로 다시 마감하면 해제) · 시가총액 = 상장주식수 × 종가 (ETF·지수 제외)
