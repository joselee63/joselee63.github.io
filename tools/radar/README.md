# 종베 레이더 (1단계) — 내 PC 전용 종가베팅 판단 보드

사이트에 올리지 않고 내 PC에서만 도는 보드입니다. 평일 15:00~15:27에 자동으로 갱신되고, 결과는 `radar-out/`에 쌓입니다(git 제외).

## 처음 한 번

1. **키움 OpenAPI 신청**: [openapi.kiwoom.com](https://openapi.kiwoom.com/main/home)에 로그인 → OpenAPI 사용 신청 → 앱 등록 → **실전** App Key / Secret 발급. 포털이 IP 등록을 요구하면 이 PC의 공인 IP를 등록합니다.
2. **키 등록**: `tools/radar/radar.bat setup-kiwoom`을 더블클릭하거나 명령창에서 실행합니다. 키를 붙여넣어도 화면에 보이지 않고, Windows 자격 증명 관리자(`kiwoom-real`)에 저장됩니다. 파일이나 저장소에는 남지 않습니다.
   - 키움 공식 CLI(`kiwoomcli setup`)로 이미 등록했다면 이 단계는 건너뛰어도 됩니다. 보드가 그 자격 증명을 그대로 씁니다.
3. (선택) **네이버 뉴스**: 네이버 검색 API는 2026-07-31부터 네이버 클라우드 **NAVER API HUB**에서만 새로 발급됩니다.
   - 발급: [ncloud.com](https://www.ncloud.com) 콘솔 → Application Services → NAVER API HUB → 이용 신청 → Application 등록(검색 > 뉴스) → Client ID/Secret 확인 → `radar.bat setup-naver`
   - '이용 관리'에서 하루 한도를 1,000건 정도로 걸어 두세요. 보드는 하루 약 200건을 씁니다. 지금은 한시적 무료이고, 유료로 바뀌면 사전 공지가 나옵니다.
   - 약관상 검색 결과는 '그대로 보여주는' 용도만 허용되고 AI 요약·학습은 금지됩니다. 그래서 보드는 헤드라인을 화면에만 보여주고, 기록에는 뉴스 건수만 남깁니다.
   - 키가 없어도 보드는 돌아가고, 뉴스 칸이 '네이버 뉴스 검색' 링크로 바뀝니다.
4. **점검**: `radar.bat check`. 이 네트워크의 공인 IP도 함께 출력합니다.

### 노트북으로 옮겨 다닐 때 (키움 IP 등록)

- 키움 REST API는 미리 등록한 공인 IP(최대 10개)에서만 토큰이 발급됩니다. 집, 회사처럼 평일 15시에 자주 있는 곳의 IP를 등록해 두세요. 위치는 포털 '계좌 App Key 관리'의 'IP 주소등록'입니다.
- 등록 안 된 네트워크에서는 키움 부분만 멈춥니다. 보드는 자동으로 '장 마감 기준' 화면으로 바뀌고, 오류 줄에 현재 IP가 나옵니다. 그 IP를 포털에 추가하고 '지금 갱신'을 누르면 됩니다.
- 휴대폰 핫스팟은 연결할 때마다 IP가 바뀌는 경우가 많아 맞지 않습니다.
- 등록된 네트워크 사이를 옮기면, 보드가 새 IP로 토큰을 다시 받습니다.

처음 실행할 때는 `%LOCALAPPDATA%\krsc-radar-venv`에 전용 파이썬 환경을 만듭니다(1~2분, Python 3.12 필요).

## 매일

- `radar.bat`을 실행하면 브라우저에 `http://127.0.0.1:8790`이 열립니다. 창을 닫으면 멈춥니다.
- 자동 갱신 시각(거래일만):

  | 시각 | 하는 일 |
  |---|---|
  | 08:40, 19:40 | 기초 데이터 받기 |
  | 09:06 | 어제 후보의 시가 기록 |
  | 15:00 ~ 15:27 | 7번 갱신. 15:20부터는 예상체결가 기준 |
  | 15:36 | 종가 확정 스냅샷 |

  '지금 갱신' 버튼으로 언제든 갱신할 수 있습니다.
- PC 로그인 때 자동 실행하려면 시작 프로그램 폴더(`Win+R` → `shell:startup`)에 `radar.bat` 바로가기를 넣으세요.

## 화면

- **A. 시황 판단**: 권장 투입을 계산합니다(계좌 × 기본 투입 × 계단20 × 요일·뜨거운 날 배수 × FOMC). 항목마다 근거 수준이 붙습니다.
- **B. 후보**:
  - 대형주 등급: 사이트 퀀트·실전 추적과 같은 규칙입니다.
  - 전체: 연구 최종 규칙입니다.
  - 제외: 상한가 터치 후 풀린 종목과 +25% 이상 종목입니다.
  - 표시 항목: 마감 위치, 거래량 배수, 밤 끼(과거 종베 갭 성향), 나스닥 민감도 β, 테마 동반·연속일, 어제 15:30 이후 공시(성격 태그), 뉴스, 주문 용량 경고.
  - 행을 누르면 공시·뉴스·같은 테마 종목을 펼칩니다. 왼쪽 칸을 체크하면 '내 선택'으로 기록됩니다.
- **C. 기록**: 다음날 시가 결과를 대형 상위 3, 전체 상위 3, 내 선택으로 나눠 보여줍니다(최근 20거래일, 비용 후).

## 파일

- `radar.py`: 수집·계산·예약·로컬 웹 서버
- `kiwoom.py`: 키움 REST 조회 API만 씁니다(ka10027·ka10001·ka20001). 주문 기능은 없습니다.
- `board.html`: 화면
- 기초 데이터: `tools/closebet/radar_base.py`가 closebet.yml(평일 18:37)에서 만들어 릴리스 `closebet-data/radar_base.json`에 올립니다.
- `radar-out/`:
  - `latest.json`: 최근 갱신 결과
  - `snap/날짜/시각.json`: 매 갱신 스냅샷(3~6개월 뒤 검증용)
  - `final.json`: 15:36 종가 확정본
  - `results.csv`: 다음날 시가 결과
  - `picks.json`: 내 선택
