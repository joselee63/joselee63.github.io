# 종베 레이더 — 내 PC 전용 종가베팅 판단 보드

사이트에 올리지 않고 내 PC에서만 도는 보드입니다. 화면은 세 가지 모드로 나뉩니다.

| 모드 | 시간 | 하는 일 |
|---|---|---|
| **15시 종가** (1단계) | 15:00~15:36 | KRX 종베 판단: 시황 판단(권장 투입) + 후보표 |
| **NXT 애프터** (2단계) | 16:00~20:03 | 오늘 후보의 NXT 가격, NXT 장후 급등·급락과 원인(장후 공시·새 뉴스·텔레그램), 저녁 나스닥 선물 |
| **아침 점검** (2단계) | 08:05~08:46 | 어제 후보·내 선택·어제 NXT 급등 종목의 NXT 프리 가격, KRX 예상체결가, 밤사이 선물 |

결과는 `radar-out/`에 쌓입니다(git 제외).

## 처음 한 번

1. **키움 OpenAPI 신청**: [openapi.kiwoom.com](https://openapi.kiwoom.com/main/home)에 로그인 → OpenAPI 사용 신청 → 앱 등록 → **실전** App Key / Secret 발급. '계좌 App Key 관리'에서 이 PC의 공인 IP를 등록합니다.
2. **키 등록**: `tools/radar/radar.bat setup-kiwoom`을 실행합니다. 키는 화면에 보이지 않고, Windows 자격 증명 관리자(`kiwoom-real`)에 저장됩니다. 파일이나 저장소에는 남지 않습니다.
   - 키움 공식 CLI(`kiwoomcli setup`)로 이미 등록했다면 이 단계는 건너뛰어도 됩니다. 보드가 그 자격 증명을 그대로 씁니다.
3. (선택) **네이버 뉴스**: 네이버 검색 API는 2026-07-31부터 네이버 클라우드 **NAVER API HUB**에서만 새로 발급됩니다.
   - 발급: [ncloud.com](https://www.ncloud.com) 콘솔 → Application Services → NAVER API HUB → 이용 신청 → Application 등록(검색 > 뉴스) → Client ID/Secret 확인 → `radar.bat setup-naver`
   - '이용 관리'에서 하루 한도를 1,000건 정도로 걸어 두세요. 보드는 하루 약 300건을 씁니다.
   - 약관상 검색 결과는 '그대로 보여주는' 용도만 허용되고 AI 요약·학습은 금지됩니다. 그래서 보드는 헤드라인을 화면에만 보여주고, 기록에는 뉴스 건수만 남깁니다.
4. (선택) **텔레그램 실시간**: `radar.bat setup-telegram`
   - my.telegram.org → API development tools에서 api_id/api_hash를 만들어 넣습니다.
   - 그다음 전화번호 → 텔레그램 앱으로 온 코드 → (설정했다면) 2단계 비밀번호를 직접 입력하고, 받을 채널 번호를 고릅니다.
   - 세션 파일은 `%LOCALAPPDATA%\krsc-radar\`에 저장됩니다. **계정 열쇠와 같으니** 공유하거나 옮기지 마세요. 보드는 글을 읽기만 합니다.
   - 받은 글은 `radar-out/telegram/날짜.jsonl`에만 저장되고, 보드 후보·NXT 표에 종목 언급 수로 붙습니다.
5. **점검**: `radar.bat check`. 이 네트워크의 공인 IP도 함께 출력합니다.

처음 실행할 때는 `%LOCALAPPDATA%\krsc-radar-venv`에 전용 파이썬 환경을 만듭니다(1~2분, Python 3.12 필요).

### 노트북으로 옮겨 다닐 때 (키움 IP 등록)

- 키움 REST API는 미리 등록한 공인 IP(최대 10개)에서만 토큰이 발급됩니다. 평일 15시와 저녁에 자주 있는 곳의 IP를 등록해 두세요.
- 등록 안 된 네트워크에서는 키움 부분만 멈추고, 오류 줄에 현재 IP가 나옵니다. 그 IP를 포털에 추가하고 '지금 갱신'을 누르면 됩니다.
- **PC가 절전 상태면 예약 갱신이 돌지 않습니다.** 15:00~15:36과 19:55·20:03, 다음날 08:46·09:06 기록이 빠지면 검증 자료에 구멍이 생깁니다. 노트북을 덮어도 절전에 들어가지 않게 하거나, 이 시간대를 꾸준히 지키기 어렵다면 서버(고정 IP 클라우드)로 옮기는 것을 권합니다.

## 매일

- `radar.bat`을 실행하면 브라우저에 `http://127.0.0.1:8790`이 열립니다. 창을 닫으면 멈춥니다. 이미 켜져 있으면 브라우저만 열고 끝납니다(중복 실행 방지).
- 화면 모드는 시각에 맞춰 자동으로 바뀝니다(07~09시 아침 점검, 15:40~21시 NXT 애프터, 그 외 15시 종가). 위 버튼으로 직접 바꿀 수도 있습니다.
- 자동 갱신 시각(거래일만):

  | 시각 | 하는 일 |
  |---|---|
  | 08:05·08:20·08:31·08:40 / 08:46 | 아침 점검 / 08:46 프리·예상체결 확정 기록 |
  | 08:40, 19:40 | 기초 데이터 받기 (08:40엔 키움 테마 구성도) |
  | 09:06 | 어제 종베 후보의 시가 기록 + 어제 19:55 NXT 목록의 프리·시가 기록 |
  | 15:00 ~ 15:27 | 15시 모드 7번 갱신 (15:20부터 예상체결가 기준) |
  | 15:36 / 15:37 | 종가 확정 스냅샷 / KRX 전 종목 종가 저장 (NXT 장후 변화 계산용) |
  | 16:00·17:00·18:00·19:00·19:30·19:45 | NXT 애프터 갱신 |
  | 19:55 / 20:03 | NXT 19:55 스냅샷(검증 기준) / NXT 마감 스냅샷 |

  '지금 갱신' 버튼은 보고 있는 모드를 갱신합니다.
- PC 로그인 때 자동 실행하려면 시작 프로그램 폴더(`Win+R` → `shell:startup`)에 `radar.bat` 바로가기를 넣으세요.

## 화면

### 15시 종가
- **A. 시황 판단**: 권장 투입을 계산합니다(계좌 × 기본 투입 × 계단20 × 요일·뜨거운 날 배수 × FOMC). 항목마다 근거 수준이 붙습니다.
- **B. 후보**:
  - 대형주 등급 / 전체(연구 최종 규칙) / 제외(상한가 터치 후 풀림·+25% 이상)로 나뉩니다.
  - 표시 항목: 마감 위치, 거래량 배수, 밤 끼, 나스닥 민감도 β, 키움 테마(+ 동료 기반 추정 테마), 어제 15:30 이후 공시(성격 태그), 뉴스, 텔레그램 언급, 주문 용량 경고.
- **C. 기록**: 다음날 시가 결과를 대형 상위 3, 전체 상위 3, 내 선택으로 나눠 보여줍니다(최근 20거래일, 비용 후).

### NXT 애프터
- **저녁 시황**: 15시 이후 나스닥·S&P 선물 변화(±0.5% 넘으면 경고), 해외 시세, 오늘 밤 이벤트.
- **① 오늘 종베 후보의 NXT 가격**: KRX 종가 대비 NXT 장후 변화, 장후 새 재료.
- **② NXT 장후 급등**: NXT 현재가 ÷ KRX 종가 기준 +2% 이상, 거래대금 10억 이상인 종목입니다. 원인을 세 가지로 나눕니다.
  - 재료형: 15:20 이후 공시·새 뉴스·텔레그램 언급이 있음
  - 동반형: 같이 움직이는 종목 중 재료형이 있음
  - 미확인: 원인을 못 찾음
- **③ NXT 장후 급락**: −3% 이하 종목입니다. 장후 악재를 확인하는 용도입니다.
- **NXT 기록**: 19:55에 NXT에서 샀다면 다음날 시가·08:46 프리에 팔 때 얼마였는지를 원인별로 집계합니다(검증 중, 20거래일 미만은 참고만).
- 키움 REST에는 KRX/NXT 괴리율 순위 API가 없습니다. 그래서 15:37에 저장한 KRX 전 종목 종가와 NXT 전 종목 현재가(등락률 상위·하위·보합 목록)로 직접 계산합니다.

### 아침 점검
- 종목: 어제 후보(대형·전체 상위 5), 내 선택, 어제 NXT 장후 급등 상위 15.
- 표시 항목: 어제 종가, 어제 NXT 19:55, NXT 프리 현재가(08:00~), KRX 예상체결가(08:30~), 밤사이 선물×β 추정, 장후 공시, 텔레그램 언급.
- 규칙: 종베 보유 종목은 **09:00 시가 동시호가 전량 매도**(검증됨).

## 파일

- `radar.py`: 수집·계산·예약·로컬 웹 서버
- `kiwoom.py`: 키움 REST 조회 API만 씁니다(ka10027·ka10001·ka20001·ka90001·ka90002). 주문 기능은 없습니다.
- `tg.py`: 텔레그램 수신(선택, 읽기 전용)
- `board.html`: 화면
- 기초 데이터: `tools/closebet/radar_base.py`가 closebet.yml(평일 18:37)에서 만들어 릴리스 `closebet-data/radar_base.json`에 올립니다.
- `radar-out/`:
  - `latest.json` · `latest_nxt.json` · `latest_am.json`: 모드별 최근 결과
  - `snap/날짜/`: 시각.json(15시), nxt_시각.json, am_시각.json, final.json(15:36), krx_close.json(15:37), nxt_1955.json, nxt_close.json, am_0845.json
  - `results.csv`: 종베 후보 다음날 시가 결과
  - `results_nxt.csv`: NXT 19:55 → 다음날 프리·시가 결과
  - `picks.json`: 내 선택
  - `telegram/`: 받은 텔레그램 글(선택)
